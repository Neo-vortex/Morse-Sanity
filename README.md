# Morse Sanity

A Flutter app for learning Morse code, with Dit the signal lamp as your
coach. It has a level-based course for receiving, sending and the NATO
alphabet, simulated on-air contacts, and seven emulated telegraph keys. It
works fully offline, in English and Persian, with no ads or in-app purchases.

**Try it in your browser:** https://neo-vortex.github.io/Morse-Sanity/ ·
**Android:** grab the APK from [Releases](../../releases).

## Features

**Course: 194 receive + 194 send + 29 NATO levels (417 total), 78 challenges**
- Letters (starting with E and T), similar-sounding letters, numbers and
  number groups, punctuation, prosigns, mixed reviews, Q-codes, 88 CW
  abbreviations, words, radio vocabulary, callsigns, sentences and QSO
  phrases.
- More than 2,200 practice words. See [Word lists](#word-lists).
- Timed **challenge levels** with no hints, which you can retry as often as
  you like.
- 1–3 stars per level (70 / 80 / 90 %). Passing a level unlocks the next one,
  or turn on *Unlock all levels* in settings.
- Three-step hints, and an on-screen answer keyboard in seven layouts or
  shuffled for every level.

**NATO alphabet track**: meet three code words at a time, with the ICAO
pronunciation (and Persian script). Pick, then recall, then type them. After
that come the ICAO figures, spelling words and callsigns with word chips, and
decoding code words back into text.

**On the air (simulated contacts)**: a short, coached CW contact with a
friendly operator, driven by an offline finite-state machine.
- **Letters** mode highlights each character live as it sounds.
- **Dots & dashes** mode shows the code itself. Tap a word to decode it, and
  key your reply with dit/dah buttons or a single telegraph key.
- Dit explains what the other station is waiting for and offers example
  replies, and *Explain* breaks any line down (UR, QSB, 579…).
- Band conditions (QSB, QRM, QRN) shape the S-meter and the reports, and a
  finished contact earns a QSL card.

**Sending keys**: straight key, dit/dah buttons, sideswiper (cootie), bug,
single-lever paddle, iambic mode A and iambic mode B, with a swap option for
left-handed operators. On a hardware keyboard, use space or the ←/→ (or `[`/`]`) keys.

**Output and radio simulation**: sound, on-screen light, flashlight and
vibration, in any combination. Radio noise comes in white, pink or receiver
hiss, at the intensity you choose, and covers all playback, including your own
keying.

**Also included**: a custom challenge builder, Koch-method lessons, quick
drills, a text ↔ Morse translator, a reference chart (characters, prosigns,
Q-codes, abbreviations, NATO), statistics, streaks, XP and daily goals.

## Word lists

The word lists are generated by `tool/wordlists/` into `lib/data/word_bank.dart`:
- **Basic English**: C. K. Ogden's 850-word core vocabulary (1930, public
  domain).
- **Common words**: the most frequent words in public-domain Project
  Gutenberg novels (`mine_gutenberg.py`).
- **Radio words**: curated amateur-radio vocabulary, plus terms mined from
  public-domain radio and telegraph books (*The Radio Amateur's Hand Book*,
  *Lessons in Wireless Telegraphy*, …) and reviewed by hand.

```sh
python3 tool/wordlists/mine_gutenberg.py   # downloads texts, writes candidates
python3 tool/wordlists/gen.py              # regenerates word_bank.dart
```


## Releases

[`.github/workflows/release.yml`](.github/workflows/release.yml) analyzes,
tests and builds the APK on GitHub Actions, signs it, and attaches it to a
GitHub Release:

- every push to `main` publishes a **pre-release** tagged `v<version>-build.<run>`
- pushing a tag such as `v1.2.0` publishes a **full release**

CI signs with a **throwaway test key** that it generates on every run. No real
key is stored anywhere. Because each build has a different signature, Android
won't install one build over another, so uninstall the old version first. For
store releases or seamless updates, create a real keystore and point
`android/key.properties` (gitignored) at it:

```properties
storeFile=/absolute/path/to/release.jks
storePassword=...
keyAlias=...
keyPassword=...
```
